Practica de Cifrado Cesar manual y con fuerza bruta.

*** 'ROMPER_CC' y 'GENERADOR' utilizan la libreria 'langdetect' y es necesario instalarla para que funcionen.
*** El texto cifrado mostrado es "El eclipse fu3 ay3r".

1. 'CC' es el archivo con el cifrado manual, el cual requiere de una clave exacta para dar con la solucion.
2. 'ROMPER_CC' es el archivo con el cifrado de fuerza bruta que dara hasta 3 posibles soluciones.
3. 'GENERADOR' es el archivo que genera el texto cifrado.
